운동별 최근 기록 및 추정 1RM

추정 1RM은 Epley 공식(weight × (1 + reps/30))을 사용합니다. 고반복·부분 반복·보조 머신의 값은 실제 1RM과 차이가 큽니다.

휴대폰 홈 화면에 설치

HTTPS로 배포한 웹 주소에서 접속하세요. Android Chrome: 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가. iPhone Safari: 공유 → 홈 화면에 추가.

오프라인에서도 실행할 수 있습니다. 기록은 현재 기기에만 저장되므로 JSON 백업을 주기적으로 보관하세요. HTML 파일(file://)로 열면 PWA 설치와 오프라인 기능이 동작하지 않습니다.

데이터 관리

현재 버전은 로그인·서버 없이 브라우저의 로컬 저장소에 기록됩니다. 다른 기기와 자동 동기화되지 않으며 브라우저 데이터를 삭제하면 기록이 사라질 수 있으니 JSON 백업을 권장합니다.

불러오기는 기존 기록을 덮어씁니다. 저장 전 자동 검증하며 확인을 요청합니다.

추천 기준 (초기 버전)

동일 운동의 가장 최근 수행 기록에서 모든 계획 세트를 완료했는지와 마지막 세트의 RPE를 확인합니다. RPE ≤ 8이면 +2.5kg(하체 복합운동은 +5kg), 8~9이면 유지 또는 +2.5kg, RPE ≥ 9이면 유지합니다. 실패 세트가 있으면 유지하거나 감량합니다. 이는 개인화된 의학적 조언이 아닌 초기 규칙이며, 통증·폼 문제·피로가 있으면 증량하지 마세요.
