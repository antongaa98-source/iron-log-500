IRON LOG 500 v1.2

1. Upload the entire contents of this folder to an HTTPS static web host (e.g. GitHub Pages or Netlify).
2. Open the HTTPS URL in Chrome on Android.
3. Chrome menu > Install app / Add to Home screen.
4. Records are stored in the browser on that device. Export JSON backup regularly.
5. A file:// HTML opened directly cannot be installed as a PWA.
6. Existing v1.1 records on file:// may not automatically appear at the new HTTPS origin. Export a JSON backup in v1.1 and import it into the hosted app.
